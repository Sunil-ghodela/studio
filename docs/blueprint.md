# **App Name**: TaskMaster

## Core Features:

- Task Management: Create, edit, and delete daily tasks with deadlines.
- File Attachment: Attach relevant files and videos to tasks for better context and reference.
- Prioritization: Rank tasks by importance, such as using a simple 'High,' 'Medium,' and 'Low' priority to show urgency and importance of a task. The AI tool can automatically suggest setting task importance using the contents of a task as context.
- Progress Tracking: Mark tasks as complete and view a summary of daily accomplishments.

## Style Guidelines:

- Primary color: Sky blue (#72BCD4) to evoke a sense of calmness and productivity.
- Background color: Very light gray (#F0F4F7), providing a clean, non-distracting backdrop.
- Accent color: Muted orange (#FFA726) to highlight important actions and deadlines, creating a visual contrast without overwhelming the user.
- Body and headline font: 'PT Sans', a modern sans-serif for readability.
- Simple, line-based icons to represent task categories and actions, maintaining a clean and consistent look.
- Clean, card-based layout for tasks to aid focus. Display associated video using preview thumbnails.
- Subtle animations when tasks are marked as complete.
